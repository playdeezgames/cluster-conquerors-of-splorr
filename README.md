# Cluster Conquerors of SPLORR!!

Conquer the cluster. Everybody hates you. The Homeowners' Association meets every 25 turns.

A turn-based space strategy metaphor by TheGrumpyGameDev, an homage to the original Master of Orion (1993). Odin compiled to WebAssembly, drawn on a canvas. Work in progress: see `DESIGN.md` (the specification) and `PLAN.md` (the build plan).

```bash
tools/test.sh     # native tests, wasm checks and a build
tools/serve.sh    # build and serve on http://localhost:8000/
```
