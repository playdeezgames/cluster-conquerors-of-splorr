## What this repository is

**Cluster Conquerors of SPLORR!!**, a new game by TheGrumpyGameDev, started November 10, 2026: an homage to the original DOS Master of Orion (SimTex and MicroProse, 1993), a turn-based space 4X, mashed up with the tropes of SPLORR!! games the way Blustery Bulwark of SPLORR!! was made from Castle of the Winds.

It is **an homage, not a remake** of Master of Orion. Do not reuse its races, race names, leader names, story, text, icons or art (no Psilons, Klackons, Darloks, Mrrshan, Sakkra, Silicoids, Alkari, Bulrathi, Meklars; no Orion or Guardian by those names; the stand-ins are the Clubhouse and its space moth). Genre mechanics (colony sliders, ship design, range, tech fields, a galactic council vote) are fair game.

`DESIGN.md` is the specification. It records the user's decisions (dated, in their words; the twelve proposals and the details were all decided November 10, 2026), the two trope inventories and what is still open; only the user moves an item to Decided. `PLAN.md` (November 10, 2026) is the build plan: three slices, slice 1 in ten steps, each ending playable in the browser and tested natively; its "Proposed" parts are Claude's until the user decides them. The user said to build on November 10, 2026; steps 0 (the scaffold) and 1 (a cluster to look at) are done. Work one step at a time and record what changed in `PLAN.md`.

The vault at `/home/yermom/git/bok-of-splorr/splorr/` is the shared body of knowledge for all SPLORR!! games and holds the standing rules. Read its `Home.md` first. This game's note is `Games/Cluster Conquerors of SPLORR!!.md`. When a decision or a fact about the game changes, update that note and its `Home.md` row as well. `Gotchas.md` in the vault has the WebGL, wasm RNG and Odin lessons; read it before writing code. The scaffold follows Blustery Bulwark's (`/home/yermom/git/blustery-bulwark-of-splorr`) and the vault's `Tech/Odin wasm recipe.md`.

## Commands

```bash
tools/test.sh                  # native tests (odin test, one thread), wasm checks of both packages, then a real wasm build
tools/build.sh [--size]        # wasm build into build/web (--size for shipping)
tools/serve.sh                 # build and serve on http://localhost:${PORT:-8000}/
tools/pages.sh                 # tests, size build, copy into docs/ for GitHub Pages; never commits or pushes
./shippit.sh [--push]          # tests, size build, zip; butler push to itch.io only with --push (only on the user's "ship")
python3 -I tools/extract_gfx.py [--sheet out.png]  # regenerate src/game/gfx.odin and font.odin (add tiles to PICKS)
python3 -I tools/make_cover.py # regenerate the placeholder assets/cover.png
tools/make_shots.sh            # render a real frame natively: assets/screenshots/01-cluster.png and assets/portal.png (the portal card picture)
```

The browser pane's launch config `conquerors-web` (port 8767, in the vault's `.claude/launch.json` and this repo's) serves `build/web`; run `tools/build.sh` first. The pane does not run frames until a screenshot is taken.

## Architecture

Odin compiled to `js_wasm32` (stack decided November 10, 2026), a 480 by 270 software framebuffer of Sweetie-16 palette indices drawn to a canvas (no WebGL).

- `src/game/` is the pure rules package (`package game`, no `core:os`, no `core:fmt`; `Text`, `add` and `add_int` build strings): `game.odin` (state, `Command`, `Pointer`, `command`, `pointer`, the news ticker), `cluster.odin` (stars, planets, the generator `make_cluster`, `star_toward` for moving the cursor, `star_near` for clicks; tuning at its top), `rng.odin` (splitmix64; the whole cluster comes from the game's seed, so it is the same on wasm and native), `render.odin` (star map, side panel, news), `screen.odin` (layout constants, `Frame`, palette, `Gfx` enum, drawing and text). `gfx.odin` and `font.odin` are generated by `tools/extract_gfx.py`; never hand-edit them. Tests are `*_test.odin` with `#+build !js` as their first line; `dump_test.odin` writes a frame with `-define:DUMP_PLAY=<path.ppm>` (seed `DUMP_SEED`, 8 by default, chosen for a busy portal picture). On-screen text names real keys ("Enter/OK"), never command names like Confirm.
- `src/web/web.odin` (`package main`, `#+build js`) is the thin browser layer, imported as `tggd:game` (`-collection:tggd=src`). the page calls `platform_start` once with a seed (fresh, or `?seed=N` from the URL, logged to the console); odin.js calls the exported `step` each frame; the page copies the RGBA frame when `platform_frame_ready` returns 1 and forwards input through `platform_command` (a `game.Command`) and `platform_pointer` (framebuffer pixel and a `game.Pointer`: mouse, right mouse, touch).
- `web/index.html` maps keys (arrows, numpad, Home/End/PgUp/PgDn for diagonals, Enter, Space or 5 to confirm, Escape or Backspace to go back, T to end the turn, F for feedback), the mouse and touch (pointer events), the gamepad (d-pad or stick, A confirm, B back, Start ends the turn) and the touch pads (a 3 by 3 d-pad with OK in the middle, and OK, Back, Turn; shown on the first touch; on screens under 500 px tall the canvas leaves 108 px each side for them) to those calls. The `Command` order there must match `game.odin`. The footer holds the credits, the AI disclosure, the back links and the "Send feedback" link; the LootLocker game is not set up yet (the user's console setup), so the form cannot send until `domain` and `key` are filled in.
- Layout: the star map is 30 by 20 cells of 12 px at the top left (the galaxy is larger and scrolls with the cursor), the side panel on the right, a three-line news ticker across the bottom.

## Standing rules (full text in the vault's `Home.md`)

- **"Push" means `git push`; "ship" means itch.io.** Do neither unless the user says that word. One ship a day through Coxswain (`ship_today` before, `ship_complete` after); scheduling is not permission.
- **GitHub Pages first.** The repo is public (`playdeezgames/cluster-conquerors-of-splorr`). **Pages is live since November 10, 2026** at https://playdeezgames.github.io/cluster-conquerors-of-splorr/, served from `main` `/docs`. To update it: `tools/pages.sh`, commit `docs/`, push (each push needs the user's go-ahead).
- **Release standard** from the start (`Tech/Release standard.md`): `ITCH_DESCRIPTION.md`, `assets/cover.png` (630 by 500), `assets/screenshots/`, `devlog/YYYYMMDD/`, `tools/ship.sh` and a one-line `shippit.sh` that pushes only with `--push`. The page footer carries back links, the AI disclosure and a "Send feedback" link to the shared LootLocker form (`Tech/LootLocker.md`).
- **Public repo: no 1-Bit Kingdom art**, ever. Prefer CC0 sets (Urizen, Bountiful Bits, Bit Bonanza) and keep every licence record and credit.
- If the ROM font 8x8 turns up, ask the user before replacing it (DINOBYTE first, then Public Pixel).
- In player-facing text and itch copy the game is a **"Metaphor"**, never a "Game", and the voice says **"yer"**, never "your" or "you're".
- Do not describe or "fix" deliberate design (brutality, odd rules) as a problem once the user has decided it.
- Anything an AI agent posts on itch.io says it was posted by an AI agent.
